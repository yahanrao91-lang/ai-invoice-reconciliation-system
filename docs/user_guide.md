# 用户操作手册

## 1. 首次安装

```bash
cd "D:\eGG\Python学习咪咪\AI票据审核与采购对账系统"
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Windows 也可双击 `run.bat` 一键启动。

## 2. 生成演示数据（可选）

```bash
.venv\Scripts\python.exe scripts\generate_demo_data.py
```

## 3. 启动

```bash
.venv\Scripts\python.exe -m streamlit run app.py
```

浏览器打开 `http://localhost:8501`，左侧导航选择功能页。

## 4. 各页面操作

### 4.1 首页：业务总览

展示对账任务总数、匹配成功任务、存在异常任务、待人工审核异常、重复发票数量，以及最近任务列表。

### 4.2 文档管理

1. 「批量上传文档」选择多个 PDF/PNG/JPG/XLSX 文件。
2. 填写任务名称，点击「创建对账任务并处理」。
3. 系统自动完成：导入 → 提取 → 三单匹配。
4. 下方「文档列表与状态」可查看每份文件的类型、状态、提取方式；删除未提交的错误文件。

> 相同文件（SHA-256 重复）会明确提示，不会重复登记。

### 4.3 AI 信息提取

1. 选择任务与文档。
2. 查看：文档类型、提取方式（text/ocr/ai/offline/manual）、可信度参考值、缺失字段提醒。
3. 三个标签页：OCR/原始文本、结构化 JSON、字段来源证据。
4. 如需修正：填写「字段路径」（如 `supplier_name`、`total_amount`、`lines[0].quantity`）、新值、原因、审核人，点击「保存修正」。修正会保留修改前后值并写入审计记录。

### 4.4 三单匹配

- 查看采购订单、发票、收货记录明细。
- 查看「匹配结果」：每行的订单数量/实收数量/发票数量/单价、匹配依据、状态。
- 异常按严重程度以颜色图标列出。
- 可点击「重新执行匹配」刷新。

### 4.5 人工审核

- 逐条展示待处理异常（open 状态）。
- 填写审核意见与审核人，点击「确认通过」或「驳回」。
- 下方展示审核操作历史（含修改前后值、原因、时间）。

### 4.6 历史记录与报告

- 选择历史任务查看详情。
- 点击「生成并下载 Excel 对账报告」，得到七张工作表的 `.xlsx` 文件。
- 查看该任务的操作审计日志。

### 4.7 系统状态与配置

- 查看 OCR 引擎状态、LLM 是否启用。
- 维护商品别名映射（规范键 → 别名）。

## 5. 启用真实 AI 提取

1. 复制 `.env.example` 为 `.env`。
2. 填写 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`，设 `LLM_ENABLED=1`。
3. 重启应用。之后「AI 信息提取」页的提取方式将显示 `ai`。

> 未配置时系统运行在「离线演示模式」，用本地规则解析，界面会明确标识。

## 6. 常见问题

- **OCR 状态显示不可用**：检查是否安装了依赖（`pip install -r requirements.txt`），或换 `OCR_ENGINE=tesseract` 并安装 Tesseract 可执行文件。
- **图片识别不准**：图片质量差、字体小或倾斜会导致识别偏差，请人工在「AI 信息提取」页复核修正。
- **离线模式解析不到字段**：离线解析面向随项目提供的模板格式，真实异构票据请启用真实 LLM 或人工录入。
