# 系统截图

本目录存放系统的实际运行界面截图，用于 GitHub 作品集展示。共 6 张，均来自真实运行界面（演示数据均为虚构）。

| 序号 | 文件名 | 展示功能 | 在业务流程中的作用 |
|------|--------|----------|--------------------|
| 1 | `01_业务总览.png` | 首页业务总览 | 展示任务、文档与整体处理状态，是系统入口 |
| 2 | `02_AI信息提取.png` | AI 结构化字段提取 | 展示文档类型、提取方式、字段完整度参考值、缺失字段提醒，以及 OCR/原文、结构化 JSON、字段来源证据标签页 |
| 3 | `03_字段来源证据.png` | 字段来源与证据展示 | 字段与原始文本片段对照，支撑人工复核，体现可追溯性 |
| 4 | `04_三单匹配.png` | PO/Invoice/GRN 三单匹配 | 展示三单核对结果与异常检测列表 |
| 5 | `05_人工审核历史.png` | 人工审核留痕 | 展示字段修正与异常确认/驳回记录，体现 Human-in-the-Loop 闭环 |
| 6 | `06_Excel对账报告.png` | Excel 对账报告 | 展示可下载的对账报告汇总页 |

图片均为 PNG，命名与根目录 `../README.md` 的「系统截图」章节引用完全一致。

> 说明：页面中的「字段完整度参考值」仅表示当前文档类型适用字段的缺失情况，是缺失字段数量的启发式参考，不是 AI 模型准确率，也不代表票据真实性。
